## 修改姓名和祝福

编辑 `src/data/birthday.js`。最常修改的是：

- `name`：寿星姓名
- `birthday`：生日日期
- `identity`：院校信息
- `heroLine`：开场主文案
- `finalWish`：结尾完整祝福
- 每张照片的 `caption` 和 `note`
- `position`：照片裁切焦点，例如 `50% 30%`


## 发布到 GitHub Pages

项目已经准备好自动部署配置。把代码推到 GitHub 的 `main` 分支后：

1. 打开仓库 `Settings`。
2. 进入 `Pages`。
3. 将 `Source` 设为 `GitHub Actions`。
4. 等待 Actions 中的 `Deploy birthday page` 完成。

后续每次推送到 `main`，网页都会自动更新。

## 推送时需要的 GitHub 授权

最省心的方式是在这台电脑上通过 GitHub 浏览器窗口登录并授权。当前环境已经安装 Git Credential Manager，第一次使用 HTTPS 推送时会弹出授权页；不需要把 GitHub 密码或 Token 发到聊天里。

开始前只需确认：

- GitHub 账号已经登录
- 仓库名称
- 仓库设为公开还是私有

也可以使用以下备用方式：

- Fine-grained personal access token：限制到目标仓库，并开启 `Contents: Read and write`；由于项目包含自动部署文件，同时开启 `Workflows: Read and write`
- SSH：把这台电脑的 SSH 公钥添加到 GitHub，私钥始终保留在本机

GitHub Pages 的部署流程使用仓库自动提供的 `GITHUB_TOKEN`，不需要再配置额外的云服务密钥。
